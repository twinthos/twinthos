THE PLAIN-ENGLISH DECODER

No jargon left unexplained.

Forty-three short answers to the terms behind AI, automation, business data and costs. In an article, hover or tap any underlined term for a quick explanation.

Explore all 43 definitions ＋
AI
Software trained to recognise patterns and produce useful answers or actions. It can be wrong and still needs checks.
AI agent
Software that can take steps towards a goal by choosing and using tools within its permissions.
Digital employee
An AI system configured to handle a defined business role or workflow with rules and human oversight.
Chatbot
A chat-based assistant. Some chatbots can remember context or connect to tools, depending on how they are set up.
Automation
A repeatable task or process handled by software instead of a person doing every step.
Workflow
The sequence of steps that takes work from an incoming request to a completed result.
Large language model (LLM)
The language-processing model that helps an AI system read, write, reason and respond.
Generative AI
AI that creates content such as text, images or audio in response to instructions.
Machine learning
A way to develop software by learning patterns from examples rather than writing every rule by hand.
Prompt
The instruction or context given to an AI system, for example a task description or a question.
Prompt injection
When untrusted content tries to trick an AI agent into ignoring instructions or misusing its tools.
Hallucination
When AI gives an answer that sounds convincing but is false or unsupported.
API
A defined way for one piece of software to request data or an action from another.
Integration
Connecting separate tools so information or tasks can move between them.
Token
A small piece of text that an AI model processes. Providers often charge based on token use.
Context window
The amount of text and other information a model can work with in one request.
Inference
Using a trained model to generate a response or decision for a new input.
Retrieval-augmented generation (RAG)
Giving an AI model relevant documents or search results as evidence before it answers.
Knowledge base
A managed collection of documents and answers people or software can look up.
Business memory
The stored context an agent is allowed to retrieve, such as current rules and approved records.
Permissions
Rules that define which files, tools and actions someone or an AI agent is allowed to access.
Audit trail
A dated record showing what happened, what changed and sometimes who approved it.
Human in the loop
A workflow where a person checks or approves important steps before they finish.
Escalation
Passing an unusual, sensitive or uncertain case to a person who can decide what happens next.
Pilot
A limited trial used to test whether an approach works in real conditions before expanding it.
Deployment
Making a piece of software available for real users or business work.
Return on investment (ROI)
A comparison of the value gained from an investment against what it cost.
Profit and loss (P&L)
A financial summary showing a business's income, expenses and profit or loss.
Uptime
The time a service is available. It does not say how much useful work it completed.
Latency
How long a system takes to respond to a request.
Transcription
Turning spoken words from a call or recording into written text.
Webhook
An automatic message sent from one app to another when a specified event happens.
UK GDPR
Rules governing how organisations handle people's personal information in the UK.
Personal data
Information that identifies someone, or could reasonably help identify them.
Data retention
The rules for how long information is kept, when it is deleted and who controls it.
Encryption
Scrambling data so it cannot be read without the right key.
Fine-tuning
Additional training that adapts an existing AI model for a specific task or style.
Guardrails
Checks and restrictions intended to stop an AI system taking unsafe or unauthorised actions.
Vendor lock-in
A situation where changing software suppliers becomes expensive or difficult because of dependencies.
Concurrency
More than one task being processed during the same period; this does not mean every task finishes correctly.
Structured data
Machine-readable information added to a page to describe its subject and relationships.
Service-level agreement (SLA)
A contract that defines expected service performance, support and remedies for failures.
AI model
The trained software component that processes inputs and produces predictions or outputs.
