Read the limitations

Security is a boundary.
Not a badge.

This is not a claim that any arbitrary AI agent is protected. The reference adapter enforces only its own exposed tool operations. An agent with unrestricted shell, network or host access could bypass it.

Threat-intelligence feeds are not proof that a system is uncompromised. Hash-chained evidence is not an immutable or externally notarised log. CI checks are not the same as third-party penetration testing.

Future integrations require verified identity, a mandatory execution path, isolated runtime permissions, approval handling and adversarial testing before deployment.
