Agents have permissions, and that changes everything

A chatbot sits in a window. It answers questions. It does not send emails, book meetings or move money. An AI agent does those things, which means it has credentials.

Credentials are attack surface. Every permission you grant is a path an attacker can follow. The agent reads your inbox. The attacker steals the agent's token and reads your inbox. The agent writes to your CRM. The attacker injects a prompt and writes to your CRM.

The difference between a chatbot and an agent is behaviour, plus permissions, plus memory. Behaviour is the feature. Permissions and memory are the risk.

The five things to check before go-live

Not all audits are the same. For AI agents, the minimum viable audit covers five areas.

What to checkWhat good looks like
PermissionsLeast privilege. The agent can only touch the systems it needs, and nothing else.
LoggingEvery action is recorded, timestamped and readable by a human.
Failure modeYou can show what happens when the agent hits an error, and you can stop it.
Data flowsYou know where the agent's memory lives, who can read it, and how it is protected.
Prompt injectionThe agent has been tested against known injection patterns and has a recovery plan.

These five checks take an afternoon. They prevent the kind of breach that takes three months to contain.

Questions people actually ask

What is an AI agent security audit?

A structured review of the agent's permissions, memory, logging, integrations and failure modes before it goes live. It covers access control, data flows, prompt injection risk, and what happens when the agent makes a mistake.

How often should I audit my AI agents?

At least once per quarter, and every time you add a new integration, change permissions, or upgrade the underlying model. CVE feeds change weekly, so continuous monitoring is better than periodic audits.

Can an AI agent be hacked?

Yes. If the agent has access to your email, calendar, files or customer records, then a compromised agent token or a successful prompt injection attack gives the attacker the same access. The attack surface is real.
