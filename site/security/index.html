Your AI agent stack, audited by someone who builds them.

Twinthos audits AI agent deployments for enterprises, brands and public sector organisations. CISA KEV, EPSS, MCP security, prompt injection, lockfile analysis and incident response. The open-source Sentinel is the core. The audit is the proof.

What the audit covers

  1. 01

    AI vulnerability monitoring

    The Twinthos AI Security Sentinel monitors NVD for AI-related CVEs, enriches them with CISA KEV and FIRST EPSS scores, and alerts your team in real time. github.com/twinthos/ai-sec-sentinel.

  2. 02

    MCP security review

    MCP servers are the bridge between your agent and your data. We audit server provenance, permission scope, transport security and drift monitoring. The Langflow CVSS 9.9 flaw showed why this matters.

  3. 03

    Prompt injection and red-team lite

    We test your agent against known prompt injection patterns, data exfiltration paths and agent collusion risks. 70% of production agents fail at least one injection test.

  4. 04

    Lockfile and dependency analysis

    Your agent stack depends on libraries, frameworks and models. We scan requirements files and lockfiles for known vulnerable versions, cross-referenced with CISA KEV and EPSS scores.

  5. 05

    Permissions and least privilege

    Every permission is a path an attacker can follow. We map what your agent can reach, what it can do, and what it should not be able to touch. Least privilege, verified in writing.

  6. 06

    Incident response and runbooks

    A breach is not the time to discover your logs are empty. We design the incident response plan before go-live: named owners, runbooks, tested stop procedures, and a clear escalation path.

Open-source core

The Twinthos AI Security Sentinel is a single Python script that monitors the NVD feed for AI-related CVEs, enriches them with CISA KEV and FIRST EPSS scores, scans lockfiles for known vulnerable versions, and sends Telegram alerts.

No API keys. No cloud subscription. No vendor lock-in. Run it on any machine with Python 3.9 or later. The repository is at github.com/twinthos/ai-sec-sentinel.

The Sentinel is used by security teams, AI engineers and CISOs who want continuous monitoring without the noise. It filters the NVD feed for AI-related entries, checks them against CISA's actively exploited list, and ranks them by real-world exploit probability.

When CVE-2026-105740 dropped, the Sentinel flagged it within hours. That is the difference between a manual check and a continuous one.
