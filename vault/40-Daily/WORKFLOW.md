# Daily Summary Workflow

## When

End of each day — or after any significant work block.

## What to Write

1. **What happened** — Bulleted list of work done, decisions made, things built
2. **What I learned** — New facts, insights, mistakes, patterns
3. **Decisions made** — Durable decisions with rationale
4. **Open loops** — Things still in progress, next actions
5. **Files changed** — Notes created or modified

## Rules

- Keep it factual. No narrative fluff.
- Link to related notes with [[wikilinks]].
- If something is a durable fact, also add it to /10-Memory/ or /../.hermes/MEMORY.md.
- If something is uncertain, mark it as a candidate in /Memory-Review/.
