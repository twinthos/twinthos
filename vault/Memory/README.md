# Memory — Perpetual Knowledge Base

> **This vault is perpetual. Nothing is ever deleted. Every note lives forever.**

## Purpose

This is the agent's persistent memory on the Orgo desktop. Every conversation, decision, learned fact, and insight is written here. Memory compounds over time — the agent gets smarter every day.

## Rules

1. **Never delete.** When something changes, add a new note explaining the update. Leave the old note.
2. **Write everything.** Conversations are summarized and stored. Decisions are logged. Mistakes are documented for learning.
3. **Organize by topic.** Create folders for domains (e.g., Twinthos, Orgo, Client-X).
4. **Date everything.** Every note has a date in its filename or frontmatter.
5. **Link everything.** Connect related notes with [[wikilinks]].

## Structure

```
Memory/
├── README.md              # This file
├── Identity/
│   ├── Who-I-Am.md        # Agent identity and mission
│   └── Skills.md          # What the agent can do
├── Twinthos/
│   └── (business knowledge)
├── Orgo/
│   └── (desktop knowledge)
├── Clients/
│   └── (per-client folders)
├── Decisions/
│   └── (key decisions log)
└── Daily/
    └── 2026-09-27.md     # Daily log
```

## Daily Workflow

At the end of each day, write a summary to `Memory/Daily/YYYY-MM-DD.md`:
- What was done
- What was learned
- Decisions made
- Next steps
