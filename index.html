The problem

Software multiplied.
Work didn't disappear.

Every new system promised efficiency. But every system also created another place someone had to check, update, copy from, paste into and remember.

The software changed. The work moved between it.

People became the glue between systems.

CHECK Look it up. Read it. Confirm it.
CHASE Send it again. Follow up. Wait.
COPY From here. Into there. Again.
UPDATE Change one system. Then the next.
BOOK Find the slot. Confirm it. Record it.
FOLLOW UP One message becomes four.
MOVE Information from one system to another.

The belief

Human intelligence is too valuable
to spend operating software.

People should decide, create, negotiate and solve. Machines should handle the repeatable operational work around those decisions.
